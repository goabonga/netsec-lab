# netlab-tap

Intercept traffic by tapping the physical medium (copper or fibre).

> Scope: Requires physical access and a TAP/optical coupler - conceptual here.

Layer **L1** - part of [netsec-lab](../../README.md).

```bash
netlab-tap brief     # what this module teaches
netlab-tap attack --i-own-this-network   # lab only
netlab-tap detect
netlab-tap defend
```

Full lesson: see the [documentation](https://goabonga.github.io/netsec-lab/layer-1-physical/network-tapping/).
