# netlab-vlan

Escape your VLAN via DTP negotiation or 802.1Q double tagging.

Layer **L2** - part of [netsec-lab](../../README.md).

```bash
netlab-vlan brief     # what this module teaches
netlab-vlan attack --i-own-this-network   # lab only
netlab-vlan detect
netlab-vlan defend
```

Full lesson: see the [documentation](https://goabonga.github.io/netsec-lab/layer-2-link/vlan-hopping/).
