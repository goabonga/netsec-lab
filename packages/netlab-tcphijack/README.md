# netlab-tcphijack

Inject into / reset an established TCP session.

Layer **L4** - part of [netsec-lab](../../README.md).

```bash
netlab-tcphijack brief     # what this module teaches
netlab-tcphijack attack --i-own-this-network   # lab only
netlab-tcphijack detect
netlab-tcphijack defend
```

Full lesson: see the [documentation](https://goabonga.github.io/netsec-lab/layer-4-transport/tcp-hijacking/).
