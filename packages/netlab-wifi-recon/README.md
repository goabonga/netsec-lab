# netlab-wifi-recon

Harvest SSIDs, BSSIDs and clients from the air, passively.

> Scope: Requires a Wi-Fi NIC in monitor mode - not replayable in the netns lab.

Layer **L1** - part of [netsec-lab](../../README.md).

```bash
netlab-wifi-recon brief     # what this module teaches
netlab-wifi-recon attack --i-own-this-network   # lab only
netlab-wifi-recon detect
netlab-wifi-recon defend
```

Full lesson: see the [documentation](https://goabonga.github.io/netsec-lab/layer-1-physical/wifi-recon/).
